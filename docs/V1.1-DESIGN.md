# SENTINEL Enterprise V1.1 design contract

The accepted V1.0 WPF desktop, Core, Infrastructure, engines, service, SQLite schema and deterministic evidence models remain the foundation. No Electron or application rewrite is introduced.

## Shared visual language

Use Segoe UI Variable/Segoe UI, 28px page titles, 20px section headings, 16px card headings, 14px body and table text, and a minimum 12px metadata size. Shared resources define 4/8/12/16/24/32 spacing, 12px card corners, 40px minimum control height, neutral navy dark surfaces and neutral light surfaces. Severity has a text label alongside color. Vector geometry icons are shared across navigation and graph classes.

Navigation is grouped into Observe, Exposure, Analyze, Respond, Intelligence and System. Narrow windows use compact navigation with tooltips and accessible route names; page content reflows rather than reducing type size. The environment badge always identifies DEMO synthetic evidence or LIVE authorized scope. Assessments are on demand; the maintenance service is never described as a network scanner.

## Evidence and workflows

All metrics, graphs, paths, inspector details, timelines and report previews derive from the active persisted snapshot and the accepted engines. Unknown coverage is displayed as unknown. Risk estimates are described as modeled estimates with evidence confidence, never as verified risk removal.

Asset and finding selection open a record workspace with related evidence, history and remediation. Existing business-context and finding disposition operations continue through the audited coordinator. Under-review and remediation planning are separate workflow metadata and do not close findings or change scoring. Workflow files are versioned, environment separated and atomically saved without replacing the evidence database.

The evidence graph begins with aggregated classes and exposes a clearly bounded actual-node focus view. Search, type/relationship filters, selection, pan/zoom, fit and path highlighting expose collected relationships without implying exploitation. Defensive paths display typed nodes and directional connectors; their break workspace explains existing engine recommendations and verification.

The offline analyst retains conversation context and links its real evidence citations back to records. Inference is explicitly labeled. Report Studio offers supported export formats and truthful configuration; unsupported charts/provider connections are never simulated.

## Verification and delivery

Run the accepted v1.0.0 build and product/engine suites before UI edits. Re-run all suites after changes. Execute actual installed WPF navigation, filters, record selection, graphs, analyst, reports, preferences and immediate theme changes. Render every route in both themes across 1366x768, 1920x1080 and 2560x1440 at equivalent 100/125/150% DIP sizes; document that bitmap scaling is not a real OS DPI transition. Inspect rendered PNGs and fix visible issues.

The Windows gate validates the maintenance service, installed application, actual V1.0-to-V1.1 upgrade preserving evidence/settings and uninstall retaining operator data. Publish new v1.1.0 EXE/ZIP assets with SHA-256 round-trip verification. Preserve all v1.0.0 history and assets. Unsigned installer and exact Windows editions/DPI not physically exercised remain explicit release limitations.
